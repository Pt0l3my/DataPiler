DataPiler 0.1.0 is the first release: a local companion for Smithbox that reads Elden Ring's data from your own
install, in a browser tab, for EldenNet's research.

**Get started**
- Download `DataPiler-0.1.0.zip`, check it against `DataPiler-0.1.0.zip.sha256`, unpack it anywhere, and start
  `DataPiler.exe`. Windows SmartScreen may warn the first time, as the exe is unsigned: More info, then Run anyway.
- You need Windows 10 or 11, Python 3.10 or newer, and Smithbox and the game installed by you.
- The first start asks before installing three Python libraries from pypi.org (grpcio, protobuf, typing-extensions),
  each file checked against its sha256. Later starts use no network.

**What it does**
- Shows Smithbox's and the game's status, extracts data by type or bundle, runs job files dropped on the page, and
  logs to its PowerShell window and the Terminal tab.
- Reads from Smithbox's local server with read calls only, and only while the game is closed.
- Keeps the game's text and data on your PC. A share file holds numbers and counts only, never a whole table or
  column, and must pass six checks before it is written.

**Before you share anything**
- Set **Expansion installed** in Settings: share files wait for it.
- Smithbox's server has no password: switch it off in Smithbox's `Startup.json` when you are done.

**Known limits**
- This version has been tested on invented data only, not yet against a real Smithbox and game.
- DataPiler cannot yet see which project Smithbox has open: check it is the one set in Settings.
- Map placements need a list of maps; "all maps" is not supported yet.
