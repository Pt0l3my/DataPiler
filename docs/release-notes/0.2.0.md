DataPiler 0.2.0 adds an Update… button, and finds your folders for you.

**Coming from 0.1.0: unpack 0.2.0 by hand, once**
- 0.1.0 cannot hand over to the updater, so this one update is by hand. Quit DataPiler, download
  `DataPiler-0.2.0.zip`, check it against `DataPiler-0.2.0.zip.sha256`, and copy what its `DataPiler` folder holds over
  your DataPiler folder, replacing the files there. Your settings, workspace, share folder, logs, jobs and Python
  environment are not in the zip, so they stay as they are. From 0.2.0 on, the button does it.

**The Update… button**
- In the top bar. Three presses: **Update…** asks GitHub for the latest release, **Download** fetches it into
  DataPiler's own `update\` folder, **Install and restart** swaps it in. Nothing reaches the internet without the
  press before it, and nothing checks on its own.
- Before anything is unpacked, the download is checked: its size, the release's own `.sha256`, GitHub's own digest
  of the file (both must agree), the zip's shape, and every file in it against the release's manifest.
- Install and restart: DataPiler stops, and its window backs up every file it will touch, writes the new ones,
  checks each one, and starts the new version. The swap never touches your workspace, share, logs, jobs, settings or
  Python environment; if a release changes the Python libraries, the window asks Y first, as at the first start, and
  keeps the old ones until the new ones work. Any failure puts everything back, and so does the window if the swap
  is cut off (at once, or at the next start if the window was closed). If the new version stops before its page
  comes up, the window offers **R** to go back.

**Finding your folders**
- On Settings, each folder has **Detect** and **Set folder…**, with a check line under it. Detect reads the running
  Smithbox, Smithbox's own record of its projects for the project and game folders, and Steam's files as a
  cross-check. Nothing is saved until you press **Use**.
- DataPiler now sees Smithbox start and stop while it runs, whichever of its exes you start (such as
  `Smithbox.Vulkan.exe`).
- **Set folder…** opens a folder picker in the page. It lists folder names only, never files.
- **Mask paths on this page** (Settings, off by default) hides your folders on the page, for screenshots.

**Not tried on a real PC yet**
- The download from GitHub, the swap, R and the putting back of a swap cut off; Detect on a real Steam install and
  with Smithbox's real project record; the Smithbox watcher on Windows' own process list; and the picker on real
  drives. Each has been tested on invented data only. The first real update through the button will be from 0.2.0
  to the release after it.
